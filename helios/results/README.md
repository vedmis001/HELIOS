# HELIOS Co-Simulation Results (`helios/results/`)

This directory stores all generated waveform figures, full-resolution timeseries datasets, and federate logs from the **150 MW Hyperscale Datacenter Fault-Trip & Reconnection Study** (Bus 5385, 161 kV, ACTIVSg2000 synthetic Texas grid).

## 2. Timeseries Datasets (`data/`)

Each JSON file contains scenario metadata, adaptive scheduler performance metrics (`total_steps`, `emt_sync_calls`, `surrogate_bypasses`, `avg_dt_ms`), and a full-resolution `history` dictionary (`t_s`, `v_mag_pu`, `freq_hz`, `p_mw`, `q_mvar`, `p_ups_mw`, `v_dc_v`, `dt_s`, `skip_emt`):

- **`results_cosim_instant_step.json`** — Coupled TS–EMT co-simulation with uncoordinated instantaneous breaker reconnection at `t = 2.0 s` (triggers converter inrush, secondary PCC voltage dip, grid-coupled UPS support pulse, and immediate `-20 MW` bulk battery recharge).
- **`results_cosim_staged_ramp.json`** — Coupled TS–EMT co-simulation with a grid-friendly `400 ms` closed-transition soft walk-in ramp (`t = 2.0 → 2.4 s`) and deferred `-8 MW` trickle recharge (`t >= 2.65 s`).
- **`results_no_ts_stiff_grid.json`** — Baseline standalone EMT run against an infinite bus (`V = 1.0056 pu`, `f = 60.000 Hz` locked) illustrating the grid-side dynamics missed without TS coupling.

## 3. Federate Logs (`logs/`)

Saved execution logs from live HELICS / PSS/E / PSCAD runs:
- **`psse_federate.log`** / **`helios_psse.log`** — PSS/E TS federate step telemetry (parsed by `plot_results.py`).
- **`pscad_federate.log`** / **`helios_pscad.log`** — PSCAD EMT federate protection, reconnection, and ComFab socket logs.
- **`broker.log`** — HELICS broker federation coordination log.
- **`helios_psse_channels.out`** — Binary PSS/E dynamic channel output file (`dyntools` compatible).
