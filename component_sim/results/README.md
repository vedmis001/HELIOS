# Component Simulator & Validation Results (`component_sim/results/`)

This directory contains saved circuit traces and verification/benchmark figures generated by [`component_sim/run.py`](../run.py), [`tests/`](../tests/), and [`validation/`](../validation/).

- **`data/`** — CSV node-voltage and branch-current timeseries traces (e.g., `ups_slice.csv`, `ups_slice_test.csv`) used for direct error comparison against PSCAD `.psout` / `.out` outputs via `validation/compare_pscad.py`.
- **`figures/components/`** — Per-component verification waveforms (`rc_test.png`, `rl_test.png`, `rlc_test.png`, `battery_test.png`, `buckboost_test.png`, `machine_test.png`, `transformer_ac.png`, `transformer_dc_step.png`, `ups_slice.png`).
- **`figures/benchmarks/`** — Fixed vs. adaptive time-stepping benchmark plots (`adaptive_benchmark_rlc.png`, `adaptive_benchmark_ups.png`).
- **`figures/slides/`** — Publication and presentation figures generated by `validation/generate_slide_figures.py` (`slide1_llm_emt_interface.png`, `slide2_llm_adaptive_stepping.png`).
